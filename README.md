# Cartório EBAC 📜

Este projeto foi desenvolvido como parte do curso **Desenvolvedor Full Stack Java** da EBAC.  
O objetivo é simular um sistema de cartório simples utilizando a linguagem C.

## 🚀 Funcionalidades
- Cadastro de usuários
- Listagem de registros
- Busca de informações
- Exclusão de registros

## 🛠 Tecnologias utilizadas
- Linguagem C
- Compilador GCC (ou equivalente)

## 📂 Estrutura do projeto
- `Trabalho_EBAC.c` → código-fonte principal
